RAG Engine — 13 层模块化检索引擎

GitHub 公开

生产级 RAG 全链路：混合检索 → 重排序 → 自省 → 安全 → 记忆

  • 13 层可插拔管道：Baseline → Compression → Ranking → Rewriting → Judge → Security → Router…，每层独立开关可配置
  • 混合检索：BM25 关键词 + 向量语义 + RRF 倒数秩融合，支持多跳检索
  • Self-RAG 三级自省：检索质量 → 上下文充分性 → 答案真实性，按置信度分级触发
  • 多模态：CLIP 图文联合嵌入（以文搜图 / 以图搜图）；长期记忆 ChromaDB 持久化
  • 安全闸口：Unicode 规范化防注入、提示注入扫描（5 级风险）、敏感数据脱敏、限流
